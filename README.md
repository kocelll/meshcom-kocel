# MeshCom kocel💣

Wydania aplikacji **MeshCom kocel💣** (Android) i firmware **MeshCom RM** (oparty na MeshCom 4.40a) dla testerów.

👉 **Pliki do pobrania: zakładka [Releases](../../releases)** — najnowsze wydanie jest na górze.

- **Aplikacja:** `MeshCom-RM-Mod.apk` — zainstaluj na Androidzie (zezwól na instalację z tego źródła).
- **Firmware:** pliki z nazwą płytki:
  - `… - pelna instalacja.bin` — pierwsza instalacja kablem (ESP32 / ESP32-S3),
  - `… - aktualizacja.bin` — aktualizacja OTA, najwygodniej z aplikacji (Start → „Aktualizacja firmware”),
  - `….uf2` / `… - aktualizacja DFU.zip` — płytki nRF52 (RAK4631, T-Echo, T114, Faketec v4).
- **Instrukcja:** `kocel💣 MeshCom RM Mod - INSTRUKCJA.pdf` w każdym wydaniu.

Opis zmian jest przy każdym wydaniu. Uwagi i błędy zgłaszaj na Discordzie MeshCom Polska.
